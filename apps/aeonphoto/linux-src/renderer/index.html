Set up a local backend

AeonPhoto generates images 100% locally. Pick one of these, start it, then press Check again.

Option A — stable-diffusion.cpp server (recommended, lightest)

  1. Get the sd-server binary: download a release from github.com/leejet/stable-diffusion.cpp, or build from source (cmake -B build -DSD_SERVER_BUILD_FRONTEND=OFF && cmake --build build --target sd-server).
  2. Download an SD 1.5 model (~4 GB, CreativeML Open RAIL‑M license). This app ships a download-model.sh helper that fetches v1-5-pruned-emaonly.safetensors from Hugging Face with resumable curl.
  3. Start the server (default port 1234): sd-server -m /path/to/model.safetensors --listen-ip 127.0.0.1 --listen-port 1234

Option B — Stable Diffusion WebUI API

  1. Install stable-diffusion-webui and launch it with the API flag: ./webui.sh --api (serves http://127.0.0.1:7860).
  2. AeonPhoto uses POST /sdapi/v1/txt2img — no extra configuration needed.

AeonPhoto never uploads your prompts or images anywhere. If you already have one of these running on a different port, set AEONPHOTO_SDCPP_URL or AEONPHOTO_WEBUI_URL before launching.
